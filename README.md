This program writes a single word, **inflammable**, the one word to erase from the dictionary forever. It looks like it means "not flammable" — the prefix "in-" usually negates — but it means exactly the opposite: easily set on fire. The word is a trap built out of its own letters. Delete it, and nobody ever again reads a warning label, decides "inflammable" must mean safe, and learns otherwise the hard way.

## Run it

```sh
python3 main.py
```
